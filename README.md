# homebrew-tap

Homebrew formulae for my projects.

Install a formula by its full name. Homebrew adds the tap and trusts only that formula:

```sh
brew install PedroMosquera/tap/<formula>
```

| Formula | What it is |
| --- | --- |
| [`squadai`](https://github.com/PedroMosquera/squadai) | One config, every AI coding agent, zero drift. |
| [`tokenjar`](https://github.com/PedroMosquera/tokenjar) | macOS menu bar app that shows how much of each AI plan's usage limit is left. Builds from source on your Mac. |

Formulae track the latest tagged release of each project.
